# TaskFlow — JavaScript Week 5 Project

TaskFlow is a responsive task management application built with HTML, CSS and vanilla JavaScript for the Week 5 JavaScript Project assignment.

## Features
- Add, edit, delete and complete tasks
- Search tasks instantly
- Filter by status and priority
- Sort by newest, oldest, priority or due date
- Form validation
- Dynamic task counters and completion progress
- LocalStorage persistence
- Light/dark theme toggle
- Responsive desktop, tablet and mobile layout

## Concepts Demonstrated
- Variables and constants
- Functions and arrow functions
- Arrays and objects
- Conditional statements and loops
- Array methods: `filter()`, `sort()`, `find()`
- DOM selection and dynamic HTML rendering
- Event listeners and form events
- LocalStorage

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.
